# 餐飲AI助理

**讀懂你的 POS 報表，告訴你下一步。**

餐廳老闆每個月從 POS（例如 iChef）下載一長串報表，還要自己研究、整理成 Excel、再做成簡報。這個工具把這件事縮短成「把報表丟進去，直接看重點」。

## 主要功能

- **多檔一次上傳**：一次選好幾份 Excel／CSV（營運總覽、商品排行，好幾個月都可以），系統自動辨識報表類型並合併。
- **全店營運總覽**：營業額、銷售量、品項數、季節佔比，點開每一格可以看細節（年度比較、去年同月比較、80/20 分析、新品與停賣品項）。
- **兩份報表對帳**：同一段期間，「營運總覽」和「商品排行」的營業額差距超過 3% 會標示出來。
- **下一季主打推薦**：依照「下一季」（相對今天自動計算）的歷史銷量，找出一到那個季節就特別好賣的品項；資料不足時會明確提醒。
- **酒水分析（加值功能）**：清酒等級分類、客人自帶酒比例、招待支出；品名判斷不出來的酒款可交給 AI 判斷（僅完整版）。
- **執行紀錄**：每次上傳、合併、查看細節都會留下紀錄，可下載成 .txt。

## 兩個版本

| 版本 | 檔案 | 差別 |
|---|---|---|
| 公開試用版 | [`index.html`](index.html) | 不用登入；報表只在瀏覽器裡計算；歷史報表存在這台裝置的瀏覽器；沒有 AI 功能 |
| 完整版（claude.ai） | [`claude-artifact/index.html`](claude-artifact/index.html) | 在 claude.ai 上執行；執行紀錄與歷史報表存進雲端資料庫；有 AI 酒款判斷與進貨建議。此檔案是備份，直接用瀏覽器開啟時雲端與 AI 功能不會啟用 |

## 使用方式

用瀏覽器打開 `index.html`，按「使用示範資料」先看效果，或按「上傳我的報表」選擇 POS 匯出的檔案。

商品排行類的報表本身沒有日期欄位，**檔名需要包含日期**（例如 `商品排行_2026-08-01~2026-08-31.xlsx`），系統才知道是哪一段期間。

## 資料說明

- 內建示範資料是虛構的小吃店數據。
- 本專案不包含任何真實店家的報表檔案。

## 技術

- 純前端：HTML + CSS + JavaScript，單一檔案
- Excel 解析：[SheetJS](https://sheetjs.com/)（xlsx）
- 完整版的雲端資料庫與 AI 功能由 claude.ai Artifact 平台提供
