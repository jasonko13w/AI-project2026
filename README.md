# 餐飲AI助理

**讀懂你的 POS 報表，告訴你下一步。**

餐廳老闆每個月從 POS（例如 iChef）下載一長串報表，還要自己研究、整理成 Excel、再做成簡報。這個工具把這件事縮短成「把報表丟進去，直接看重點」。

## 主要功能

- **本月重點**：一打開就看到最新月份的營業額、比去年同月／上個月的變化、變化主要來自來客數還是客單價、需要注意的事，以及下一季建議主打的商品。
- **多檔一次上傳**：一次選好幾份 Excel／CSV（營運總覽、商品排行，好幾個月都可以），系統自動辨識報表類型並合併。
- **歷史報表**：每個月整理好的報表自動存起來，可以切換單一月份、全部月份、本季、去年同月，或把兩個月並排比較；可一鍵清除重來。
- **手動每日輸入**：沒有 POS 報表也能用。選日期，填品項、數量、單價（金額自動算），可加來客數與折扣；每天存一筆，系統自動加總成月報，上面所有分析照常運作。同一天重新存檔會取代舊的，不會重複加總；可看當月已輸入的日期清單與每天營業額，點一下就能修改或刪除。
- **連鎖分店**：可新增分店；檔名寫上店名（例如 `品牌A_南京店_業績概況_2026-08-01~2026-08-31.xlsx`）會自動放到那家分店。可看單一分店、全品牌加總，以及分店比較（營業額、客單價、成長率）。
- **全店營運總覽**：營業額、銷售量、品項數、下一季預估營業額，點開每一格可以看細節（單月與多月版面不同）。
- **數字檢查**：同一段期間，「營運總覽」和「商品排行」的營業額會互相比對；會先算出這家店平常的落差（例如固定的服務費），只有跟平常不一樣才提醒。
- **下一季主打推薦**：依照「下一季」（相對今天自動計算）的歷史銷量，找出一到那個季節就特別好賣的品項；資料不足時會明確提醒。
- **酒水分析（加值功能）**：清酒等級分類、客人自帶酒比例、招待支出；品名判斷不出來的酒款可交給 AI 判斷（僅完整版）。
- **電腦、手機都好讀**：畫面會依螢幕寬度自動調整；電腦上可以按「📱 手機預覽」看老闆用手機看到的樣子。
- **系統紀錄**：每次上傳、合併、查看細節都會留下紀錄，可下載成 .txt。

## 兩個版本

| 版本 | 檔案 | 差別 |
|---|---|---|
| 公開試用版 | [`index.html`](index.html) | 不用登入；報表只在瀏覽器裡計算；歷史報表與分店存在這台裝置的瀏覽器（換電腦、換瀏覽器、無痕視窗都看不到）；沒有 AI 功能 |
| 完整版（claude.ai） | [`claude-artifact/index.html`](claude-artifact/index.html) | 在 claude.ai 上執行；執行紀錄與歷史報表存進雲端資料庫；有 AI 酒款判斷與進貨建議。此檔案是備份，直接用瀏覽器開啟時雲端與 AI 功能不會啟用 |

## 使用方式

用瀏覽器打開 `index.html`，按「先看示範資料」看效果，或按「上傳我的報表」選擇 POS 匯出的檔案。沒有任何資料時，畫面只會顯示上傳提示，不會自動帶出示範數字。

商品排行類的報表本身沒有日期欄位，**檔名需要包含日期**（例如 `商品排行_2026-08-01~2026-08-31.xlsx`），系統才知道是哪一段期間。

## 資料說明

- 內建示範資料是虛構的小吃店數據。
- 本專案不包含任何真實店家的報表檔案。

## 技術

- 純前端：HTML + CSS + JavaScript，單一檔案
- Excel 解析：[SheetJS](https://sheetjs.com/)（xlsx）
- 完整版的雲端資料庫與 AI 功能由 claude.ai Artifact 平台提供
